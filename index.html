      About this catalogue

      RepoCatalogue is a small study project: a responsive single page that reads live data from the public GitHub REST API. There are no frameworks and no build step, just semantic HTML, CSS and JavaScript.

      1. Ask

        The form checks the username before anything leaves the browser.

      2. Fetch

        fetch() with async/await loads the profile and up to 100 repositories as JSON.

      3. File

        Each repository becomes a card built in JavaScript, then filtered and sorted on the spot.

      4. Remember

        localStorage keeps your last search and reopens it on your next visit.
